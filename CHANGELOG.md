# Changelog

## [0.1.0] - 2026-10-03

First release.

### Added
- Native C++ `memcore` module with Python bindings.
- `memory_mcp` Python package and MCP server.
- Test suite.
- clang-format / clang-tidy configuration and lint script.
- README and contributing guide.

### Install

Prebuilt wheel for Windows x64, Python 3.12 or newer:

```
pip install memory_mcp-0.1.0-cp312-abi3-win_amd64.whl
memory-mcp
```
